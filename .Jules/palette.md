## 2024-05-19 - Improved OAuth flow local server callback pages
**Learning:** Adding accessible, styled HTML templates to CLI local server callbacks provides a significant "touch of delight" and better user feedback compared to raw text strings, especially when dealing with auth flows.
**Action:** Always verify local CLI servers serve accessible, semantic HTML pages (e.g., using proper tags like `<main>`, `lang="en"`, and CSS for visual feedback).
